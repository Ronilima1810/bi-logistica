# BI Logístico — Portfólio técnico

[![Abrir preview](https://img.shields.io/badge/▶_Abrir_preview_interativo-157c86?style=for-the-badge)](https://ronilima1810.github.io/formulario-de-matricula/portfolio-demos/?demo=bi)

Este repositório reúne **uma estrutura inicial** para um projeto de Business Intelligence voltado a operações logísticas.

## Demonstração visual

Acesse o [preview navegável](https://ronilima1810.github.io/formulario-de-matricula/portfolio-demos/?demo=bi) para conhecer uma proposta de visualização de indicadores de faturamento, expedição, eficiência e frete.

**Atenção:** a interface do link é um **protótipo independente**, desenvolvido exclusivamente para portfólio, com dados fictícios. Os arquivos principais de frontend/backend deste repositório ainda estão vazios; o preview não executa o software original nem se conecta a operações reais.

## Tecnologias previstas na estrutura

- Frontend com React/JavaScript
- Backend Python
- Organização de projeto com Docker

## Segurança

Nenhuma credencial, informação de cliente, base de dados, integração de transporte ou dado operacional real é necessário para utilizar o preview. Qualquer publicação de código empresarial requer autorização e revisão de segurança.
